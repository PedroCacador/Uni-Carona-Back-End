# UniCarona

UM aplicativo seguro e ágil criado para facilitar a locomoção de universitários através de um sistema estruturado de caronas, conectando motoristas e passageiros de maneira rápida.

## Tecnologias Usadas

- **Node.js**: Plataforma de execução (Ambiente base).
- **TypeScript**: Superset de JavaScript, entregando tipagem estática e segurança na compilação.
- **Express**: Micro-framework web utilizado para construir as rotas das requisições com extrema leveza.

## Como rodar o projeto

1. Em seu terminal, instale os pacotes básicos usando o instalador de sua escolha:
   ```bash
   npm install
   ```

2. Dispare o servidor em modo hot-reload com:
   ```bash
   npm run dev
   ```
